# 내 배스, 상위 몇 %? (낚맛)

배스 길이를 넣으면 낚맛 앱에 기록된 같은 달 배스 중 상위 몇 %인지 보여주는 페이지입니다. 전국·시도별 순위, 지역 런커(50cm 이상) 컬러, 사진 자랑 카드를 지원합니다.

- 주소: https://deanlee1113.github.io/nakmat-bass-rank/
- 데이터: 낚맛 앱 배스 승인 기록 10~70cm(2021.6~2026.10.2), 길이별 기록 수만 담은 집계입니다. 개인 정보는 없습니다.
- 입력한 길이와 사진은 브라우저 안에서만 쓰고 서버로 보내지 않습니다.
- 앱: https://app.nakmat.com
